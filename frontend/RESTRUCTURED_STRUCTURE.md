# CarFix Angular - Restructured

This version keeps the original frontend logic and UI, while reorganizing the app so each domain/collection has its own area and model/service files. Admin pages are included.

Main structure:
- users/
- spare-parts/
- orders/
- emergency/
- technicians/
- vehicles/
- cart/
- auth/
- landing/
- models/
- services/
- shared/
- core/guards/

`node_modules` is intentionally excluded from the delivered archive. Run `npm.cmd install` after extracting.
